# GRID / EVO · 五站训练大奖赛

2026 年 F1 当前阵容：11 支车队、22 位车手，以 2026-11-12 的 F1 官方名单为准。上海、银石、蒙扎、斯帕、巴林五站使用公开地理中心线，按各赛道官方圈长定标，以米制统一赛车与路面比例，采用简化二维物理。

**夺冠标准：同一位车手的同一个冻结模型，在五站各连续完成 3 圈，最先全部通过者夺冠。** 同一步完成时比较五站累计用时，仍相同则并列。冠军证书包含模型 SHA256、权重和五站完成步数。名字与涂装是实验身份，不代表真实车手能力；本项目与 F1 官方无关联。

浏览器访问 http://192.168.110.186:8765 。实际计算在 Jetson Orin / CUDA 12.6 / PyTorch 2.8.0 上运行。浏览器只显示状态和发送控制命令。

每位车手拥有 32 个独立候选网络，共 704 个 CUDA 网络（8→10→2，112 个参数）。统一车模、相同训练预算，车手之间不共享基因。每轮依次评估五站，每站一圈、最多 120 秒模拟时间。使用最弱站、平均进度与轻微的完赛速度奖励选择模型，每轮照常选择和进化，每完成 5 轮训练（新赛事第 5、10、15…轮）再冻结模型进行五站三圈验证。验证没有时间或两圈上限；驶出有效路面、连续六秒未刷新最远进度、倒退越过起点会失败。换模型后，五站验证全部重新开始。所有车都是互不碰撞的幽灵车；直播每位车手显示一个当前代表模型。

页面支持：查看五条赛道（预览不影响实际训练）、点击车手跟踪遥测、暂停、1×/3×/10×/30×倍率、感知射线、下载赛事存档、归档并开启新赛季。比赛规则和完整阵容在顶部及榜单底部查看。倍率是目标模拟速率，实际速度以 CUDA 步/秒为准。

赛事存档为 `checkpoints/grand-prix.json`，在赛段切换、控制操作和每 30 秒自动原子保存。保存种群、随机数状态、当前物理状态、五站成绩、冻结模型和比赛设置，重启继续原赛事。下载存档使用标准 JSON，无可执行模型反序列化。新赛季将旧存档归档为 `grand-prix-archive-*.json`。旧版 `checkpoints/best.json` 保留，未用于新锦标赛。

验证频率：训练每 5 轮检查一次；每轮仍完整训练五站并进行选择、交叉和变异。界面显示下一次验证轮次。修改频率不重置已学权重与当前赛段；正在进行的旧验证会完成，之后再完整训练 5 轮（例如第 14 轮验证结束后，下次是第 19 轮）。更换候选模型会清除旧模型的五站验证记录，避免混用证据。

冠军泛化测试：增加奥地利红牛环（`at-1969.geojson`）作为唯一留出赛道。训练与选模仍只有原五站，32 候选模型和冠军规则保持不变。冠军用证书内原始 float32 权重在红牛环连续试跑 3 圈；全程只推理，无进化、无选模、无权重修改，采用相同几何版本 3、车辆尺寸和简化物理。页面可开始/重新测试、暂停、调整播放倍率和返回原冠军成绩。重复测试为确定性重放，不是再次训练。
测试结果、各圈用时、失败原因、测试前后模型 SHA256 和模拟断点独立保存在 `checkpoints/grand-prix-holdout.json`；不会覆盖五站成绩或冠军证书。重启服务会恢复同一模型的留出赛道试跑。通过只说明该模型在这条未见赛道和当前简化物理下能完成 3 圈，不能据此断言适用于所有赛道或真实赛车。红牛环圈长采用地理数据/F1 资料的 4318m、10 弯，等宽参考 12m（FIA 资料 12–13m）：https://www.fia.com/sites/default/files/spg2022_0208_f1_mediakit_2022_eng_a4_220708_view.pdf 。

车辆物理版本 4（与赛道几何版本分开记录）：采用平面赛车参考模型，加入有限加减速、速度平方空气阻力、有限转向执行速度、转向响应延迟以及纵横向共用的摩擦圆。抓地力预算为 `1.55g + 0.0032·v²`，发动机参考加速度上限 8m/s²、制动指令上限 18m/s²，阻力项为 `0.0008·v²`；这些是本模拟器的参考调校参数，不是实际车队测量数据。高速转向请求超出预算时会限制实际转弯能力并产生推头，车速不会被瞬间调低。网络仍输出转向和目标速度，控制器通过有上限的油门/制动去追踪目标速度。页面显示实际油门、制动、横向 G 和抓地力使用率，制动时点亮尾灯。
线路没有写死为中心线或外内外。模型通过路面射线选择位置和转向，利用原有完赛时间奖励选择更有效的线路；较大转弯半径可以允许更高的物理弯速。达到全五站三圈的冠军条件不变。平面模型仍未包含真实轮胎滑移曲线、轮胎温度/磨耗、坡度、悬架和车辆之间的气动影响，不代表完整 F1 仿真。

计算优化：每 32 个模拟步检查存活模型；数量降至当前批次一半以下时缩减运算批次，淘汰模型的状态冻结。CUDA Graph 重放固定形状的单步运算，捕获/预热后恢复原状态，避免预热计入训练。固定网络以逐元素乘加计算，使不同存活批次尺寸及断点恢复保持数值一致。验证一站失败的模型不再跑后续站，全部模型失去五站资格时立即进入下一轮训练。`validationSkipped` 区分免跑与实际未完成；未通过任何一站的模型仍不能获得冠军。

历史冠军和配对的红牛环试跑存放于 Jetson 的 `records/<id>/`，包含原始完整赛事、红牛环断点和结果、当时的代码、原始文件 SHA256 清单。只读 `/api/records` 和 `/api/records/<id>/{model,holdout}` 用于页面历史冠军卡片及下载。新物理赛事从随机初始网络重新运行；历史证书与红牛环成绩属于原物理版本，未迁移为新物理成绩。`physicsVersion` 变化会使活动赛事的旧资格失效，已归档结果保持原样。

性能检查脚本：`tools/benchmark_arena.py --baseline <旧版本文件>` 比较旧物理，`tools/benchmark_arena.py --eager` 与默认优化模式比较同一新物理和同一随机初始状态。它在正常赛段结束时停止，包含图捕获开销，不用已全部淘汰后的空转夸大吞吐。具体性能受种群、赛段、存活数量和设备负载影响。
